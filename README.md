One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny: a meeting about the email ends with an email scheduling a meeting about the email. `main.ts` (Node 22, standard library only) writes that single line to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && OUTPUT_DIR=out node main.ts
```
